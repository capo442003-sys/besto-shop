# BESTO SHOP — boutique vêtements & chaussures

## Production

https://besto-shop-production.up.railway.app

1. Connexion : `admin` / `admin123`
2. Changez le mot de passe immédiatement
3. Réglages → Boutique : nom, logo, coordonnées
4. Catalogue : articles Hommes / Femmes / Enfants / Chaussures / Accessoires

Après déploiement : **Ctrl+F5** (ou vider le cache PWA).

## Identité visuelle

Atelier Mode — navy ink, bronze, typo Fraunces + Outfit (distincte de l’ancien BMB vert).
